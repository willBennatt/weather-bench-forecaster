# Learning Strategy

The goal of this project is to refresh my machine-learning skills while learning about weather data and analysis. The goal is not to become an expert in weather forecasting, but rather to quickly gain an overall understanding of the field and types of work being done. I am trying out an AI-as-teacher strategy to see whether I can learn faster with guidance.

## Workflow

I split the project into eight phases, each of which build on the previous with a specific learning goal.

For each phase, I do the following:

1. Research on my own to understand the goal of the phase and how to accomplish it.
2. Implement it on my own first.
3. Test my implementation. This is where I typically discover lots of errors and ask AI for guidance about where I went wrong and how to improve it.
4. Iterate until I'm satisfied with the results and feel I understand the phase.
5. Write up a PHASE_N doc in [phases/](./phases/).
6. Have the AI give me a test to assess my understanding. I can't move to the next phase until I pass the test and my writeup passes AI review.

## Results so far

After doing the first three phases, I've been surprised how quickly I've been able to learn and understand the concepts. Using AI for instant guidance and feedback accelerates the process.

However, I feel the ease of the process detracts from my learning. Especially when it comes to specific details like how to correctly normalize the different data types, being able to ask AI to help at the first roadblock makes it too easy to not try hard enough myself the first time. The lack of pain also makes it harder for me to remember exactly how it was done later. I think there is a direct relationship between effort and memorability - the things I still remember most from undergrad are the ones I had to beat my head against a wall to work through.

The most helpful part is definitely the quiz at the end of each phase. If I did implement something without really understanding it, this makes it very clear and forces me to go back and understand it better.

Overall I view it as a tradeoff between speed and depth: using AI makes it a lot faster to implement a project like this and understand overall themes, but it definitely hurts understanding of the details. If I had to reimplement features like the forcing parameters without access to the internet, it would be way harder for me than if I had truly struggled through it without help the first time.
